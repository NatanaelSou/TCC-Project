# Perguntas Frequentes - Projeto Premiora

## Geral

### O que é o Premiora?

O Premiora é uma plataforma que une conteúdo, comunidade e monetização em um só lugar para criadores de conteúdo. É como um híbrido entre Patreon, Discord e Instagram, mas focado em criadores independentes.

### É gratuito?

- **Para espectadores**: Sim, há conteúdo gratuito disponível.
- **Para criadores**: A plataforma é gratuita para começar, mas pode haver taxas em recursos premium no futuro.
- **Assinaturas**: Os criadores definem os preços dos tiers.

### Quais tipos de conteúdo posso publicar?

Qualquer tipo: vídeos, áudios, podcasts, posts de texto, imagens, cursos, lives, etc. A liberdade é total.

## Cadastro e Conta

### Como me cadastrar?

1. Baixe o app ou acesse a versão web
2. Clique em "Criar Conta"
3. Preencha nome, email e senha
4. Escolha se é criador ou espectador

### Esqueci minha senha

- Use "Esqueci senha" na tela de login
- Receberá um email com link para redefinir
- Links expiram em 24 horas

### Posso ter contas separadas para criador e espectador?

Atualmente não. Uma conta serve para ambos os perfis, mas você pode alternar entre eles.

## Para Criadores

### Como começar a criar conteúdo?

1. Complete seu perfil (foto, bio, links)
2. Configure seus tiers de assinatura
3. Publique seu primeiro post gratuito
4. Crie canais de comunidade

### O que são tiers?

Níveis de assinatura mensal que você configura:

- **Tier 1**: Básico (ex: R$ 5/mês) - acesso a posts exclusivos
- **Tier 2**: Intermediário (ex: R$ 15/mês) - lives privadas + bastidores
- **Tier 3**: Premium (ex: R$ 30/mês) - interação direta + conteúdo personalizado

### Quantos tiers posso criar?

Até 10 tiers por conta de criador.

### Como monetizar?

- Assinaturas mensais automáticas
- Pagamento via cartão de crédito
- Você recebe 80% do valor (20% para a plataforma)

### Preciso oferecer conteúdo gratuito?

Sim! Todo criador deve ter pelo menos um conteúdo gratuito por mês para atrair novos espectadores.

## Para Espectadores

### Como encontrar criadores?

- Navegue pela aba "Explorar"
- Use filtros por categoria
- Veja recomendações baseadas em seus interesses

### Como assinar um criador?

1. Entre no perfil do criador
2. Escolha um tier
3. Adicione cartão de crédito
4. Confirme assinatura mensal

### Posso cancelar a assinatura?

Sim, a qualquer momento:

1. Vá para "Minhas Assinaturas"
2. Selecione a assinatura
3. Clique em "Cancelar"
4. Acesso continua até o fim do mês pago

### O que acontece se eu cancelar?

- Perde acesso ao conteúdo pago
- Pode reassinar quando quiser
- Dados permanecem salvos

## Comunidade

### O que são canais?

Espaços criados pelos criadores para interação:

- **Chat**: Conversas em tempo real
- **Mural**: Posts e discussões assíncronas

### Canais são públicos?

Depende da configuração do criador:

- Alguns são livres para todos
- Outros só para assinantes de determinado tier
- Alguns são privados (convite apenas)

### Posso criar meus próprios canais?

Não. Apenas criadores podem criar canais em seus perfis.

## Técnico

### Quais dispositivos são suportados?

- **Mobile**: Android (8.0+) e iOS (12.0+)
- **Web**: Chrome, Firefox, Safari, Edge (versões recentes)
- **Desktop**: Windows, macOS, Linux (via web)

### Há limite de upload?

- Vídeos: até 2GB
- Áudios: até 500MB
- Imagens: até 50MB
- Texto: ilimitado

### É seguro?

Sim:

- Dados criptografados
- Pagamentos via gateways seguros
- Política de privacidade rigorosa
- Relatório de vulnerabilidades via SECURITY.md

### Como reportar bugs?

- Use a aba "Ajuda" no app
- Ou crie uma issue no GitHub
- Inclua: descrição, passos para reproduzir, dispositivo/SO

## Monetização

### Quando recebo os pagamentos?

- Mensalmente, no dia 1º
- Para assinaturas ativas no mês anterior
- Transferência via PIX ou conta bancária

### Há taxa da plataforma?

- 20% sobre cada assinatura
- Sem taxas ocultas
- Transparente no dashboard

### Posso mudar preços dos tiers?

Sim, mas:

- Avisar assinantes com 30 dias de antecedência
- Assinantes atuais continuam no preço antigo até renovar

## Privacidade e Segurança

### Meus dados são seguros?

Sim:

- Criptografia end-to-end em mensagens
- Dados armazenados em servidores seguros
- Conformidade com LGPD

### Posso deletar minha conta?

Sim:

1. Vá para configurações
2. "Deletar Conta"
3. Confirme (todos os dados serão removidos)

### Como funciona a moderação?

- Criadores podem nomear moderadores
- Regras definidas por canal
- Relatório de conteúdo inadequado
- Código de conduta em CODE_OF_CONDUCT.md
