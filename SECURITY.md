# Política de Segurança do Projeto Premiora

## Relatando Vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança no Projeto Premiora, por favor, ajude-nos relatando-a de forma responsável. Valorizamos sua contribuição para manter nossa plataforma segura para todos os usuários.

### Como Relatar

**Não** relate vulnerabilidades publicamente (ex: issues no GitHub, posts em redes sociais).

Em vez disso, envie um e-mail para [security@premiora.com](mailto:security@premiora.com) com os seguintes detalhes:

- Uma descrição clara da vulnerabilidade
- Passos para reproduzir o problema
- Impacto potencial
- Qualquer sugestão de correção (opcional)
- Seu contato para follow-up (opcional, mas recomendado)

### Nossa Resposta

- **Confirmação**: Responderemos ao seu relatório dentro de 48 horas, confirmando o recebimento.
- **Investigação**: Investigaremos a vulnerabilidade e forneceremos atualizações regulares.
- **Correção**: Trabalharemos para corrigir a vulnerabilidade o mais rápido possível.
- **Divulgação**: Após a correção, divulgaremos publicamente a vulnerabilidade (com crédito a você, se desejado).

### Programa de Recompensas

Atualmente, não oferecemos recompensas monetárias, mas reconhecemos contribuidores de segurança em nosso CHANGELOG.md e CREDITS.md.

### Escopo

Esta política aplica-se ao:

- Código fonte do repositório principal
- Aplicativos móveis e web do Premiora
- API do backend
- Infraestrutura relacionada ao projeto

Não inclui:

- Dependências de terceiros (relate diretamente aos mantenedores dessas bibliotecas)
- Ataques DDoS ou força bruta
- Vulnerabilidades já conhecidas publicamente

### Contato

Para questões sobre esta política: [security@premiora.com](mailto:security@premiora.com)

Obrigado por ajudar a manter o Premiora seguro!
